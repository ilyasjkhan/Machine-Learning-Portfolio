# Student Performance Prediction Model

A machine learning project using Python and scikit-learn to predict student final grades based on academic, behavioural and socio-economic factors.

---

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab

---

## Project Overview
- Cleaned and prepared student performance data for analysis
- Performed exploratory data analysis and correlation analysis
- Built and evaluated regression models to predict final grades
- Compared model performance using MAE, RMSE and R² metrics
- Visualised relationships between variables and model predictions

---

## Model Performance

### Linear Regression
- MAE: 4.13
- RMSE: 4.76
- R²: 0.75

### Random Forest Regressor
- MAE: 4.46
- RMSE: 5.21
- R²: 0.70

---

## Key Insights
- Previous academic performance was one of the strongest predictors of final grade
- Attendance and study hours showed positive relationships with outcomes
- Operational data cleaning and handling missing values significantly improved model reliability
